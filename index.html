Étape 1 : Création de l'application

Invoque ton application directement depuis les portails dimensionnels de Discord pour préparer ton bot.

  1. Ouvre le Discord Developer Portal.
  2. Clique sur "New Application" et nomme ton entité.
  3. Entre dans l'onglet "Bot" pour l'activer, puis génère ton Token.
  4. Copie également ton Client ID depuis la page d'accueil (General Information).

Étape 2 : Liaison du Token

Fournis les informations requises pour lier ton bot au backend et activer la protection totale.

Attention : Ce token est trop court ou corrompu. Regarde bien dans les ombres pour trouver le vrai.
