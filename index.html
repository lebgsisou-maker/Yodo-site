Étape 1 : Créer ton Bot Discord

Avant toute chose, tu dois créer l'application officielle de ton bot sur Discord. Suis ces instructions simples :

  1. Rends-toi sur le Discord Developer Portal.
  2. Clique sur "New Application" en haut à droite et donne-lui un nom (ex: YodoProtect).
  3. Va dans l'onglet "Bot" (dans le menu de gauche) puis clique sur "Add Bot".
  4. Sous le nom du bot, clique sur "Reset Token" et copie ton précieux token secret !
