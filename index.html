Crée ton Bot Discord

Suis ces quelques étapes simples pour configurer ton application avant de profiter des fonctionnalités avancées de YodoProtect.

01
Étape 1

Créer l'application sur Discord

Rends-toi d'abord sur le Portail Développeur Discord.

  • Connecte-toi avec ton compte Discord.
  • Clique sur le bouton en haut à droite "New Application".
  • Choisis un nom pour ton bot (ex: YodoProtect Bot), coche la case des conditions et clique sur Create.
02
Étape 2

Transformer l'application en Bot

Maintenant que ton application est créée, il faut lui donner vie :

  • Dans le menu de gauche, clique sur l'onglet Bot.
  • Clique sur Reset Token (ou Add Bot si l'option apparaît) pour générer le code secret de ton bot.
  • Attention : Copie bien ce token et garde-le secret, ne le partage jamais à personne !
03
Étape 3

Activer les Intents Privilégiés

Pour que YodoProtect puisse analyser les messages, gérer la sécurité et voir l'arrivée des membres :

  • Sur la même page (onglet Bot), descends tout en bas dans la section Privileged Gateway Intents.
  • Coche impérativement ces trois options :
    • Presence Intent
    • Server Members Intent
    • Message Content Intent
  • Clique sur Save Changes en bas de la page.
04
Étape 4

Inviter le bot sur ton serveur

Il ne reste plus qu'à l'ajouter chez toi :

  • Va dans l'onglet OAuth2 > URL Generator dans le menu de gauche.
  • Dans Scopes, coche la case
    bot
    .
  • Dans Bot Permissions, sélectionne les permissions nécessaires (ex: Administrator pour un contrôle total de sécurité).
  • Copie le lien généré tout en bas, ouvre-le dans ton navigateur et invite le bot sur ton serveur Discord !
